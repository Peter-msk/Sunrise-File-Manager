# Sunrise File Manager 1.1.0 — 테마·사용성 개선 인수인계

## 적용 내용

1. PC 테마 자동 적용: Windows `AppsUseLightTheme` 사용자 설정을 확인하고 설정 변경 이벤트 시 다시 적용. `System`/`Light`/`Dark` 선택을 세션에 저장. 기존에 직접 선택한 라이트·다크 세션은 유지.
2. 상단 분할 버튼 왼쪽에 테마 빠른 전환 버튼, 설정 메뉴의 **PC 설정 적용** 항목 추가. 분할 버튼은 선택·비선택별 배경·글자색을 모두 대비되게 적용.
3. ComboBox와 ComboBoxItem 팝업을 공통 테마 템플릿으로 대체하여 다크 드롭다운의 흰 배경/흰 글씨 문제 방지.
4. 드라이브 트리는 기본 Windows 흰색 선택 표시 대신 테마 선택 배경 사용. 폴더 펼침 이벤트의 실제 자식 탐색 연결 유지.
5. 확장자 텍스트 배지 크기와 색상 대비 개선(PDF/HWP/DOC/XLS/PPT/IMG 등), 우클릭 메뉴 최소 높이/여백 축소.
6. AI 정리창의 기본 고급 엔진 패널 접기와 작업 높이 조절로 세로 스크롤 완화. 공통 스크롤바 얇은 트랙/Thumb 테마 적용. 필요시 자동 스크롤은 계속 허용.
7. 하단 우측 공지사항/업데이트 버튼을 기존 검증·정책 처리를 갖춘 창과 연결. 해당 창도 라이트/다크 브러시 사용.
8. 앱 버전 및 설치 메타데이터 1.1.0; **실제 1.1.0 설치파일은 아직 게시하지 않음**. 현재 공개 루트 latest.json·notice.txt는 공식 1.0.0을 가리키게 유지. 차기 빌드 시 `release/NOTICE_BODY_1.1.0.txt` 사용. 이전 출시 문구 혼입 방지.

## Windows 10/11 실기 확인 필요

- 라이트/다크/PC 자동 적용 3종 + Windows 앱 테마 변경 직후 반응
- 100%, 125%, 150% DPI와 1024/1366/1920px 창 너비에서 상단 테마·분할·AI 버튼 겹침 유무
- 드라이브 선택·폴더 확장·트리 키보드 탐색, 파일 목록 확장자 배지, 우클릭 메뉴
- AI Popup 모든 ComboBox: 목록의 선택, 스크롤, 키보드 ↑↓/Enter/Esc, 비활성 상태, 계획 실행
- DataGrid/AI 작업표/미리보기 가로세로 스크롤·마우스휠/드래그
- 공지사항·업데이트 하단 버튼, 기존 중앙 Control 정책 및 SHA-256 다운로드 검증
- `BUILD_ON_WINDOWS_COMPANY.cmd` 공식 설치 파일 1.1.0 서명·설치·제거/업그레이드 검증

## 빌드/게시 정책

- 1.1.0 서명 빌드 성공 전에는 실제 다운로드 URL/해시를 만들거나 공개 `latest.json`을 변경하지 않음.
- v1.1.0 정식 설치파일 게시 후 확인된 자산 URL·SHA-256·크기로 공개 메타데이터를 개정해야 기존 1.0.0 설치본에서 업데이트가 감지됨.
- 릴리스 페이지/공지사항은 사용자 기능 안내만 작성하고 개발 로그·빌드 상세는 별도 내부 문서에 보관.
