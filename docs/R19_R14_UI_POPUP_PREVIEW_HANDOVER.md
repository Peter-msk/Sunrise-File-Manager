# Sunrise File Manager 1.0.0 — R19 R14 UI 수정 인수인계

## 기준과 자격

- 기준본: `Sunrise_File_Manager_1.0.0_R19_VISIBLE_CAPTURE_STAGE_R13_FULL_SOURCE.zip`.
- 사용자 제공 Windows 화면 6개(파일 목록, #memo, 상단 빠른 명령 행, AI 하단 도킹 등)를 근거로 변경.
- **자격: SOURCE_STATIC_PASS / WINDOWS_WPF_BUILD_AND_UI_DYNAMIC_PENDING.** 개발 호스트에 Windows WPF 런타임 및 `dotnet` 실행기가 없어 EXE 컴파일·설치 및 실화면 동작은 이 환경에서 수행하지 않았음.
- 빌드/서명 스크립트, 파일 이동·삭제 서비스, #memo 저장 및 Ollama 실행 파이프라인의 업무 로직은 변경하지 않음.

## 수정 범위

1. `Controls/ExplorerPane.xaml`: 탐색기 상단 빠른 명령 행(새 폴더·파일/잘라내기/복사/붙여넣기 등)이 차지하던 `Grid.Row` 1개를 **실제로 제거**. 코드에서 참조하는 명령 컨트롤은 숨김 상태로 보존하여 메뉴, 키보드 단축키, 정렬·보기 설정의 기존 연결을 유지. 파일 목록 이름 열 가변폭과 최소폭 지정, 긴 이름 전체 ToolTip 제공, 메타 열 표시폭 재조정. 머리글·셀 패딩 일관성 유지.
2. `Controls/FileInspector.xaml`: 상단 `상세정보 · 스마트 파일 메모` 제목과 해시/용량 버튼을 다른 줄에 배치. `스마트 파일 메모 (#memo)` 제목과 `AI 요약`/`메모 저장` 버튼을 분리. 변경 확인 버튼과 작성자 입력도 별도 행 배치하여 295~330 DIP 상세 패널에서 겹침 위험 감소.
3. `MainWindow.xaml`, `MainWindow.xaml.cs`: AI 파일 정리 패널의 탐색기 하단 도킹 영역 삭제. F8/상단 버튼/AI 연결 메뉴/파일 우클릭 `AI` 명령으로 **독립 비모달 팝업 창** 열기. 기존 `AiCommandPanel` 단일 인스턴스를 재사용해 입력·계획과 안전 확인 상태 유지. X 버튼/닫기 요청 시 미작업 상태에서는 숨겨 재진입 시 상태 보존. 실제 파일 변경 진행 중에는 창 닫기를 제한하고 원래의 취소·되돌리기 동작 유지.
4. `Controls/AiCommandPanel.xaml`: 더 넓은 팝업 창에 맞춰 입력 영역, 계획 결과 영역의 비율 변경. 결과 그리드 '변경 전/후' 가변폭 배치 및 생략 문자열의 전체 ToolTip 제공. 단계 안내 및 온보드 AI 배지 잘림 완화.
5. `Controls/FilePreviewPanel.xaml[.cs]`: 우측 미리보기 패널 두 줄로 정리된 이전/다음 페이지, 축소/확대, 너비 맞춤, 별도 창에서 보기 버튼. Ctrl+휠 및 키보드 기본 조작 추가. 이미지와 텍스트를 다르게 취급해 **텍스트 너비 맞춤에서 글자를 과도하게 축소하지 않음**.
6. `Controls/PreviewWindow.xaml[.cs]`: 독립 미리보기창 10~400% 확대 슬라이더, +/- 버튼, 100%, 너비 맞춤, 페이지 맞춤, Ctrl+휠, Ctrl+더하기/빼기/0/1/2, PageUp/PageDown, Esc. 창 크기 변경 때 너비/페이지 맞춤 비율 갱신. 파일명·상태 상세 ToolTip 제공. 읽기 전용 콘텐츠 정책 유지.
7. `App.xaml`: DataGrid 머리글과 셀의 좌측 여백 일치 및 수직 중앙 정렬.

## 사용자 조작 안내

| 화면 | 입력 | 동작 |
| --- | --- | --- |
| 파일 탐색기 | F8, 상단 `AI 파일 정리` | 독립 AI 팝업 열기/닫기 |
| 우측 미리보기 | `+` / `-`, `너비 맞춤` | 확대·축소·창 너비 맞춤 |
| 우측 미리보기 | Ctrl+마우스 휠, Ctrl+더하기/빼기/0/1 | 확대·축소, 100%, 너비 맞춤 |
| 우측 미리보기 | 이전/다음, PageUp/PageDown | 미리보기 페이지 전환 |
| 우측 미리보기 | `↗` | 큰 독립 미리보기 창 |
| 큰 미리보기 | Ctrl+마우스 휠, Ctrl+더하기/빼기 | 확대·축소 |
| 큰 미리보기 | Ctrl+0/1/2 | 100% / 너비 맞춤 / 페이지 맞춤 |
| 큰 미리보기 | PageUp/PageDown, Esc | 이전·다음 페이지, 창 닫기 |

## 확인한 항목과 남은 PC 실기 Gate

- R14 핵심 UI 계약검사 및 기존 회귀검사: `pytest tests` (실제 실행 결과는 패키지 검증 출력 참조).
- XAML XML 구문, 새 WPF 이벤트 핸들러 이름의 C# 정의 존재 여부 점검.
- 기존 CMD 설치·서명 파이프라인 손대지 않음. `tests/verify_packaging_contract.py` 별도 검사.
- **Windows 필수 확인**: 100/125/150% DPI, 단일/2/3/4분할, 작은 창과 최대화, 드래그 리사이즈, PDF 이미지·텍스트·HWPX/DOCX 미리보기, Ctrl+휠 위치/스크롤, AI 창 활성/숨김/작업 중 닫기 제한, #memo 저장/복원, 실제 설치형 빌드.
- 새 프로그램을 실행하지 않은 단계는 PASS로 표현하지 않음.
