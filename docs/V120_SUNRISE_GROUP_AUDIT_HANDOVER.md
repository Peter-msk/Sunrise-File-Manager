# Sunrise File Manager v1.2.0 — Sunrise Group 공식 제품 코드감사 및 인수인계

## 기준본·적용 기준

- 부모 소스: Sunrise File Manager v1.1.0 R23 (`Sunrise_File_Manager_1.1.0_R23_UPDATER_FILE_LOCK_HOTFIX_FULL_SOURCE.zip`).
- 목표 제품 버전: **1.2.0** / 설치형 Windows x64 .NET 10 WPF.
- 우선 기준: Sunrise Group 개발표준 v2.8 FINAL MODULAR, Sunrise Group 전용 코드개발 시방서 v1.3, 범용 코드작성 시방서 v1.3, 기존 제품의 운영 wire contract.
- 기존 GitHub v1.0.0/v1.1.0 공식 릴리스 자산과 게시된 `latest.json`, `notice.txt`의 실제 버전·해시·URL은 **수정/대체하지 않음**.
- 소스 아카이브 루트 `latest.json`은 과거 v1.0.0 시점의 보존 스냅샷일 수 있음. **실제 운영 조회는 GitHub `main/latest.json`**임. 기준본 원본과 배포본을 혼동하지 말 것.

## 설치 업데이트 수행 순서

1. 프로그램이 `Sunrise_Control/control.txt`에서 중앙 실행·업데이트 정책 확인.
2. 파일 매니저 저장소의 `latest.json`에서 제품 버전·Setup URL·SHA256·다운로드 정보를 파싱.
3. 사용자가 다운로드에 승인한 뒤 중앙 업데이트 정책 재조회.
4. 공식 HTTPS 다운로드, 파일 크기 제한 및 SHA256 검증; 임시 다운로드 파일 핸들을 닫은 뒤 확정.
5. 사용자가 **설치 실행**을 별도로 승인하면 중앙 정책 재조회. 진행 중 파일 작업·저장되지 않은 메모 확인.
6. 검증 완료된 로컬 Setup 절대경로와 현재 PID만 사용하는 **로컬 고정 OS 대기 명령** 시작. 원격 스크립트/다운로드/인증정보 사용 없음.
7. File Manager 정상 종료 → AppMutex/설치 파일 잠금 해제 → 대기 프로세스가 최대 60초까지 종료 확인.
8. 종료 완료 후 설치파일 실행 요청; Inno Setup이 기존 AppId로 설치/교체. 대기 시간이 초과하면 설치를 시작하지 않음.

- CI 실행 결과, 실제 WPF 다운로드/종료/재설치 스모크, 메모 저장 상태·파일작업 중 업데이트 방어는 **실기 검증 필요**.

## Windows 승인 시험 (반드시 검증)

1. `BUILD_ON_WINDOWS_COMPANY.cmd` 수행: 실제 WPF 컴파일·서명·설치 생성·메타데이터 최종 PASS.
2. 1.1.0 기존 설치본에서 공개 게시된 v1.2.0 `latest.json` 조회. `latest.json`은 공식 Setup 발행 **후** 실제 SHA256으로 갱신.
3. 새 버전 감지 → 다운로드 승인 → SHA256 검증 → 설치 승인.
4. File Manager 프로세스가 종료된 뒤에만 Inno Setup 실행되고 이전 버전 파일이 잠겨 있지 않은지 확인.
5. 메모 변경 미저장/파일 복사·이동·AI 작업 중 설치가 시작되지 않는지 확인.
6. 필수 업데이트 정책과 차단·점검 정책을 별도로 확인. 오프라인 캐시 정책 확인.
7. 최신 앱 재실행: 파일 탭·분할·사용자 설정·메모·미리보기·AI·공지·업데이트 확인, 라이트/다크/시스템 테마 확인.
8. 기존 공식 릴리스 보존. 릴리스 후 새 Setup과 `latest.json` 크기·해시·주소 재조회.

## 릴리스 운영 주의

- 이번 ZIP은 **1.2.0 소스 작업본**. 정식 Windows Setup 파일이 아님.
- 과거 업데이트 오류 중 R23에서 고친 내용은 **다운로드 임시파일 핸들 미해제**였고, R24(1.2.0)에서 고친 내용은 **본체 종료 전에 설치 실행하는 순서**다. 서로 다른 결함임.
- 공개 공지사항에는 개발 내부 구현·시방·소스·진단 내용을 포함하지 않는다.
- Control 서버는 제품별 공지/버전의 소유자가 아니므로 `latest.json`·`notice.txt`를 Control에 복제하지 않는다.
- 기기별 인증서 선택이나 신뢰 저장소 작업을 업데이트 클라이언트에서 수행하지 않는다.
