Sunrise File Manager v1.8.2

[1.8.0 → 1.8.2 주요 변경 및 추가 기능]
- EIASS 사업별 환경평가 업무 폴더 자동 생성: 사업정보와 저장 위치를 입력하면 내부 점검 및 최종 확인 후 누락 폴더만 생성합니다. 별도 미리보기 클릭과 중복 검토창을 없앴습니다.
- EIASS PDF 제출용 파일명 설정: 목차 일치 및 중복 검사 최적화, 일괄 이름 변경의 작업 중지·복구 처리 개선.
- 파일 작업: 분할창 간 로컬 파일·폴더 안전 이동, 복사·이동 충돌 방지, 일괄 이름 변경 중지 및 결과 안내 보완.
- 대용량 탐색: 하위 폴더 검색·필터·정렬·페이지 이동 처리 최적화.
- UI/UX: 다크·라이트 모드의 글자, 입력칸, 버튼, 메뉴, 탭, 스크롤바 및 작업 상태의 시인성과 조작성 개선.
- 개발용 빌드 안정화: .NET 10 SDK 탐색 경로 확장 및 진단 도구 추가(R03).

[Sunrise File Manager 대표 기능]
- 1~4분할 작업공간과 다중 탭: 여러 폴더를 한 화면에서 비교·관리.
- 파일 관리 및 스마트 검색: 복사·이동·이름 변경·압축/해제, 유형 필터 및 하위 폴더 검색.
- 안전한 파일 전송·폴더 비교 및 동기화: 충돌·작업 중지·복구 기록 확인, 대상에 없는 항목 추가 방식의 단방향 동기화.
- 스마트 파일 메모, 지원 문서 미리보기, 파일 상세정보: 탐색창에서 업무자료를 확인하고 정리.
- Google Drive·OneDrive 연결 및 파일 관리(공급자별 지원 범위 적용).
- 로컬 AI(Ollama) 및 규칙 기반 파일 검색·분류·정리: 계획을 확인한 뒤 실행.
- 환경영향평가(EIASS) 특화 업무폴더 생성 및 제출용 PDF 문서명 설정.

[사용 안내]
EIASS 폴더 생성은 Windows 로컬 NTFS/ReFS에서 지원하며 NAS/SMB 직접 생성은 제한됩니다. 폴더 생성 자체는 기존 파일을 수정·삭제·덮어쓰지 않습니다. 파일 이름 변경은 경로를 변경하는 작업이므로 미리보기와 결과 확인을 권장합니다. 클라우드 이동은 공급자의 보호 조건에 따라 제한될 수 있습니다.
