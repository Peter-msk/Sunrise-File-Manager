Sunrise File Manager v1.8.1

- EIASS 사업별 평가업무 폴더를 계획·재점검·최종 확인 후 생성할 수 있습니다.
- 기존 폴더나 파일은 삭제·이동·덮어쓰지 않으며, 누락된 폴더만 생성합니다.
- 중단·실패 시 이미 만들어진 폴더는 삭제하지 않고 결과를 표시합니다.
- 외부 회사·발주처 미승인 초안은 운영 생성에 포함하지 않습니다.
- 현재 폴더 생성은 Windows 로컬 NTFS/ReFS 경로만 지원합니다. NAS/SMB는 검증 후 지원 예정입니다.
- EIASS 제출용 PDF 문서명 변경 기능을 기존 방식대로 유지합니다.

사용자 데이터 보호: 파일명 변경 작업은 파일 내용을 수정하지 않지만 파일 이름은 변경되므로, 사전 미리보기와 충돌 확인을 권장합니다.
