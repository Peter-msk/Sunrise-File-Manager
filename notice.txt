Sunrise File Manager 1.3.6

Sunrise File Manager 1.3.6 업데이트 안내

[주요 개선]
- 주소표시줄 클릭 시 파일 탐색기형 폴더 탐색 트리를 펼쳐 선택할 수 있습니다.
- 빠른 이동과 기본 폴더를 선택하면 실제 드라이브 경로를 탐색 트리에 강제로 펼치지 않고 폴더 내용만 표시합니다.
- 드라이브의 펼침/접힘 버튼 클릭 영역을 넓히고 드라이브 이름 더블클릭도 지원합니다.
- 파일 목록의 빈 배경을 더블클릭하면 상위 폴더로 이동합니다.
- 드라이브 간 이동, 자연 정렬, 탐색 스크롤, 공지사항 및 업데이트 통합 버튼은 유지합니다.

[안내]
프로그램의 공지사항 및 업데이트 메뉴에서 최신 버전을 확인할 수 있습니다.
