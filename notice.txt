Sunrise File Manager 1.5.4

EIASS 제출용 문서명 일괄 변경과 파일 관리 편의 기능 안내

[EIASS 제출용 문서명 일괄 변경]
환경영향평가 보고서 PDF의 이름을 제출용 형식으로 한 번에 정리할 수 있습니다.

- PDF 파일을 선택한 뒤 '편집 → EIASS 제출용 문서명 설정…' 또는 마우스 오른쪽 버튼 메뉴에서 실행합니다.
- 평가 구분과 초안·본안·보완 등의 말머리, 4자리 또는 5자리 목차번호, 문서 제목을 조합합니다.
- 시작 번호와 증가 간격을 지정하고, 위·아래 버튼으로 파일 순서를 조정할 수 있습니다. 번호와 제목도 표에서 직접 수정할 수 있습니다.
- 목차 파일(PDF·DOCX·HWPX·HWP·TXT)을 불러오거나 목차를 직접 입력해 파일 순서를 맞출 수 있습니다. 목차에 번호가 없어도 제목이 일치하면 연결할 수 있습니다.
- 제목이 중복되거나 일치하지 않는 항목은 자동으로 추정하지 않습니다. 표시된 결과를 확인하고 필요한 항목을 직접 조정해 주세요.
- 제목의 금지 문자 정리를 선택하고, 현재 이름과 변경 후 이름을 비교한 뒤 적용할 수 있습니다. 중복 이름과 기존 파일 충돌은 적용 전에 확인합니다.
- 파일 이름만 변경하며 PDF 내용과 확장자는 유지합니다. 적용 후 Ctrl+Z로 실행 취소, Ctrl+Y로 다시 실행할 수 있습니다.
- 사후환경영향조사·약식평가 최종보고서는 말머리를 생략하며, 기후변화영향평가는 기존 이름을 유지합니다.

예시: '표지 및 목차.pdf' → '(초안) 0000 표지 및 목차.pdf'

※ 번호는 화면에서 확인한 파일 순서에 시작 번호와 증가 간격을 적용해 부여합니다. 목차의 장·절 계층번호를 자동으로 판단하는 방식은 아닙니다.
※ 스캔 목차는 텍스트를 직접 입력하거나 순서를 수동 조정해 주세요. EIASS 사이트에 파일을 업로드하는 기능은 포함하지 않습니다.

[Windows 탐색기로 하던 폴더 작업을 더 편하게]
여러 폴더와 보고서를 오가며 정리할 때 필요한 기능을 한 화면에 모았습니다.

1. 1~4분할과 다중 탭
원본·작업·제출 폴더를 나란히 열어 확인할 수 있습니다. 창을 여러 개 겹쳐 놓고 이동하는 번거로움을 줄이고, 각 영역에서 서로 다른 폴더와 탭을 사용할 수 있습니다.

2. 파일별 메모
파일을 선택해 검토 의견과 작업 내용을 메모로 남길 수 있습니다. 프로그램에서 지원하는 파일 이동·이름 변경 시 관련 메모도 함께 처리해 문서와 검토 내용을 연결해 관리합니다.

3. 미리보기와 상세정보
파일 목록을 보면서 미리보기·상세정보·메모를 함께 확인할 수 있습니다. 미리보기는 상세정보 패널과 별도로 열고 닫을 수 있습니다.

4. 문서 본문 검색과 조건 검색
지원하는 PDF·DOCX·HWPX·일반 HWP 5·XLSX·PPTX 등의 본문에서 내용을 찾고, 파일 이름·확장자·크기·날짜 조건으로 목록을 좁힐 수 있습니다. 보호·암호화 문서와 형식별 읽기 제한이 있는 자료는 검색이 제한될 수 있습니다.

5. 반복 정리 작업
일반 파일의 일괄 이름 변경, 압축 내용 확인·선택 해제, 폴더 목록 CSV 내보내기를 활용해 파일 정리와 제출 목록 작성에 드는 작업을 줄일 수 있습니다.

6. 작업 화면 복원
열어 둔 탭과 폴더, 분할 배치, 테마·화면 배율, 열 너비와 보기 설정 등을 저장해 다음 실행에서 이어서 사용할 수 있습니다.

[파일 작업 안정화]
- 일괄 이름 변경이 중간에 실패할 때 원래 이름과 메모를 복구하도록 보완했습니다.
- 실행 취소·다시 실행 중 창 종료와 추가 파일 변경을 제한하고, 실패한 항목은 재시도할 수 있도록 이력을 보존합니다.
- 메모 저장·폴더 새로고침 후 선택과 미리보기를 유지하고, 파일 위치 찾기에서 앞선 목록이 누락되던 문제를 수정했습니다.
