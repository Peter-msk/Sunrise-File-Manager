Sunrise File Manager v1.7.5 업데이트 사전 안내

[이번 주 업데이트 예정]
현재 공식 배포 버전: v1.7.0
다음 업데이트 목표 버전: v1.7.5
업데이트 예정 기간: 2026년 10월 26일(월) ~ 11월 1일(일)

Sunrise File Manager를 이용해 주셔서 감사합니다.
v1.7.0 이후 개발한 화면·검색·클라우드·파일 전송·맞춤 색상 기능을 모아 v1.7.5 업데이트를 준비하고 있습니다.

아래 v1.7.1~v1.7.5 항목은 변경 내용을 이해하기 쉽도록 개발 흐름별로 구분한 안내입니다. v1.7.1~v1.7.4가 각각 정식 배포됐다는 의미는 아니며, 최종 업데이트는 v1.7.5로 한 번에 제공할 예정입니다.

[v1.7.1 | 화면 구성과 스마트 검색 개선]
- 1~4분할 파일 탐색 화면을 정돈하고, 불필요한 상단 빠른 기능 버튼을 줄여 작업 공간을 넓혔습니다.
- 스마트 검색을 우측 도구 패널에서 쉽게 열고, 파일/폴더 구분과 문서 종류별 검색 조건을 보완했습니다.
- 검색 위치에 Windows 드라이브의 실제 이름 또는 연결된 공유 경로가 표시되도록 개선했습니다.
- 목록의 열 정렬과 검색창 안내를 정리하고, 파일 속성과 기본 파일 작업 메뉴의 사용성을 개선했습니다.

[v1.7.2 | Google Drive·OneDrive 연결]
- 각 분할창에서 내 PC·네트워크 드라이브와 Google Drive·OneDrive 작업 위치를 선택할 수 있도록 확장했습니다.
- 클라우드 연결은 선택 사항입니다. 로그인하지 않아도 기존 로컬 파일 관리 기능은 사용할 수 있습니다.
- 연결한 클라우드의 폴더 탐색, 파일 업로드·다운로드와 기본 파일 관리 작업을 지원하도록 개발했습니다.
- 자동 로그인은 사용자가 선택한 경우에만 사용하도록 설정했습니다.

[v1.7.3 | 분할창 간 파일 복사와 전송 개선]
- 로컬·네트워크·클라우드 작업창 사이에서 파일을 복사할 수 있도록 전송 경로를 확대했습니다.
- 여러 파일과 하위 폴더 복사, 복사·붙여넣기 및 드래그 앤 드롭 작업 흐름을 보완했습니다.
- 전송한 파일의 내용 일치 여부를 확인하고, 같은 이름의 기존 파일은 임의로 덮어쓰지 않도록 보호합니다.
- 클라우드 간 전송의 임시 데이터 보호와 오류·취소 상황 처리를 강화했습니다.

[v1.7.4 | 안전 이동·전송 재개·폴더 동기화]
- 파일을 복사해 확인한 뒤에만 원본 처리를 진행하는 안전 이동 절차를 보완했습니다.
- 중단된 다운로드·업로드 작업의 재개 조건을 확인하고, 파일이 달라졌거나 연결 정보가 유효하지 않으면 안전하게 중단하도록 했습니다.
- 폴더 비교 결과를 미리 확인하고, 대상에 없는 항목만 추가하는 단방향 동기화를 개발했습니다.
- 파일 충돌·접근 권한 오류에서는 임의의 덮어쓰기나 보안정책 우회 없이 사용자에게 상태를 안내합니다.

[v1.7.5 | 사용자 맞춤 라이트 색상과 화면 안정화]
- 라이트 모드에서 사용자가 메인 색상을 직접 선택하면 버튼·선택 영역·패널·테두리가 어울리는 색상으로 함께 바뀌도록 했습니다.
- 추천 색상, HEX/RGB 입력, 실시간 미리보기, 적용·취소·기본색 복원, 다음 실행 시 선택한 색상 복원을 지원하도록 개발했습니다.
- 다크모드는 기존 색상을 유지하며, 맞춤 색상은 라이트 모드에만 적용됩니다.
- 검색·클라우드·속성·전송 창의 색상 일관성, 글자 가독성, 다중 창과 고해상도 화면 구성도 보완했습니다.

[업데이트 전 꼭 확인해 주세요]
- 현재 설치 가능한 정식 버전은 v1.7.0입니다. v1.7.5는 아직 배포되지 않았습니다.
- 이번 주 일정은 예정이며, Windows 실제 실행·기능 검증, Sunrise Group 서명 및 설치파일 최종 확인 결과에 따라 변경될 수 있습니다.
- 각 기능의 최종 제공 범위는 정식 v1.7.5 설치본과 배포 안내에서 확정합니다.
- 정식 배포가 완료되면 프로그램의 업데이트 안내에서 새 버전을 확인할 수 있습니다. 배포 전에는 기존 v1.7.0을 계속 이용해 주세요.
