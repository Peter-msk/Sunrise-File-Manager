Sunrise File Manager 1.3.2

Sunrise File Manager 1.3.2은 탐색 패널과 선택·설정 복원을 개선했습니다.

[주요 개선]
- 첫 실행의 숨긴 항목·확장명·확인란·색상 구분 기본값 OFF, 저장된 선택은 유지
- 빠른 이동 아이콘 복원, 탐색 패널 고정 너비 및 가장자리 열기/닫기
- 탐색 패널 자동 숨김과 마우스 진입 시 슬라이드 표시
- 빈 영역 좌클릭 드래그 사각형 다중 선택과 가장자리 자동 스크롤
- 설정·탭·열 너비·분할 비율·AI 입력·미리보기 배율 복원 보완
- 새 탭은 내 PC, 상위 이동은 바탕화면에서 종료
- 파일 목록 선택·포커스의 흰색 표시 경로와 메뉴 구분선 개선
- 빌드 배포정보 URL 및 업데이트 설정 자동 생성 유지
