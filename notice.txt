Sunrise File Manager 1.8.0

Sunrise File Manager 1.8.0 업데이트 안내

[로컬 서명 설치본 확인 전 안내]
- 1~4분할 탐색 화면의 기본 메뉴를 표시하고 사업폴더 계획 바로가기를 추가했습니다.
- 사업번호·계약번호를 기본 폴더 계획 입력에서 제외하고, 사업명만 사업 루트 폴더에 사용하도록 정리했습니다.
- CASE-01 등의 내부 식별자가 사용자 폴더명에 들어가지 않도록 경로 계획을 수정했습니다.
- Sunrise Group 하위에 개별 프로그램과 AppData를 배치하는 공통 경로 규칙을 적용했습니다.

주의: 사업폴더의 실제 업무용 자동 생성 기능은 아직 활성화되지 않았습니다. 기본 계획과 읽기 전용 검토 기능을 제공하며, 운영용 생성 및 NTFS/SMB 안전 실기검증은 별도 완료해야 합니다.

본 안내문은 로컬 서명 빌드를 위한 버전별 소스 템플릿입니다. 이 파일의 존재만으로 정식 배포·업데이트 승인이 발생하지 않으며 기존 공개 최신 버전·정책은 변경하지 않습니다.
