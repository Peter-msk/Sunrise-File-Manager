Sunrise File Manager 1.5.0

Sunrise File Manager 1.5.0 업데이트 안내

[문서 검색]
- 일반 검색과 승인한 AI 본문 검색·규칙 분류의 읽기 범위를 통일했습니다.
- XLSX 셀·PPTX 슬라이드/발표자 노트·일반 HWP 5 본문 검색을 추가했습니다.

[탐색 편의]
- 이름 와일드카드·확장자·크기·작성/수정일 조건 필터를 추가했습니다.
- 바로가기 만들기/붙여넣기, 숨김·읽기 전용 속성 변경, 전체 결과 CSV 내보내기를 추가했습니다.
- 암호 입력 후 압축 해제와 Windows에 설치된 OCR 기능을 연결했습니다.

[경량 배포]
- 기존 .NET 10 Desktop Runtime x64를 사용하는 경량 설치형 빌드를 제공합니다.
- 실행환경이 없으면 설치 전에 안내하며 자동 다운로드하지 않습니다.
- 기존 실행환경 포함 빌드는별도로 선택할 수 있습니다.
