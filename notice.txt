Sunrise File Manager 1.7.5

Sunrise File Manager 1.7.5 버전 안내

[1.7.5 주요 변경사항 — 소스 개발 후보 / 공식 배포 전]
- 1~4분할 창에서 로컬·네트워크·Google Drive·OneDrive 작업 위치를 자유롭게 선택합니다.
- 클라우드 로그인은 선택 사항이며, 자동 로그인은 사용자가 명시적으로 설정합니다. 비밀번호는 프로그램에 저장하지 않습니다.
- 클라우드 파일 탐색·업로드·다운로드, 분할창 복사·검증 후 안전 이동, 폴더 비교·단방향 동기화 기능을 확장했습니다.
- 일시적인 네트워크 실패·파일 충돌·중단 후 재개에 관한 데이터 보호와 오류 안내를 보완했습니다.
- UI, 고해상도 배율, 키보드 및 접근성 관련 소스 마감을 진행했습니다.

주의: 이 문구는 v1.7.5 빌드에서 사용할 예정인 로컬 소스 템플릿입니다. 실제 배포·지원 기능 확정은 Windows 컴파일, GUI·실계정 검증, 그룹 서명 및 승인 후 진행합니다.
