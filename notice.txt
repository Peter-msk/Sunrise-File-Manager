Sunrise File Manager 1.7.5

Sunrise File Manager v1.7.5 정식 업데이트 안내
배포일: 2026년 10월 28일

Sunrise File Manager v1.7.5 정식 버전을 안내합니다. 여러 폴더와 로컬·네트워크·클라우드 저장소를 한 화면에서 편리하게 관리하고, 파일 전송의 안전성과 사용 편의성을 높였습니다.

[1.7.5 주요 업데이트]
- 1~4분할 파일 탐색: 최대 4개 작업 공간에서 로컬 드라이브, 네트워크 위치, Google Drive, OneDrive를 나란히 살펴볼 수 있도록 개선했습니다.
- 기능별 메뉴 그룹화: 파일 관리 / 검색·문서 / 분할·작업 공간 / 전송·복구 / 클라우드·AI / 패널·화면 / 프로그램 정보의 7개 그룹으로 메뉴를 정리했습니다.
- 클라우드 계정 관리 개선: 연결 설정·원격 탐색·파일 작업을 구분하고, 앱 Client ID 옆 '?' 버튼에서 Google Drive·OneDrive의 공식 발급 절차를 바로 볼 수 있습니다.
- 스마트 검색·파일 탐색 최적화: 이름·확장자·유형·조건 검색, 페이지 처리 및 대용량 목록 탐색을 보완했습니다.
- 안전한 파일 작업: 분할창 복사, 업로드·다운로드, 확인 후 이동, 폴더 비교 및 단방향 동기화의 충돌 방지와 결과 안내를 개선했습니다.
- 전송 상태 안내: 성공·실패·건너뜀·취소·미시작 항목을 구분하고, 연결 오류·중단 후 재개 및 복구 안내를 보완했습니다.
- 화면·접근성: 라이트 모드 사용자 맞춤 색상, 다크 모드, 고해상도 배율, 보조 패널 스크롤 및 키보드 포커스 이동을 개선했습니다.

[알아두면 편리한 기능]
- F6 / Shift+F6: 열려 있는 작업 영역 사이에서 다음 / 이전 영역으로 포커스를 이동합니다.
- Alt+Shift+F: 파일 작업 공간 집중 모드를 실행합니다.
- 1~4분할·다중 탭: 서로 다른 폴더의 파일을 비교하거나 복사할 때 유용합니다.
- 미리보기·상세정보·파일별 메모: 파일을 열기 전 내용을 확인하고 업무 메모를 관리할 수 있습니다.
- 폴더 비교·안전 단방향 동기화: 적용 전 대상을 확인하고 필요한 항목을 정리할 수 있습니다.
- 로컬 AI 연동(선택): 별도 Ollama 환경을 준비하면 지원되는 검색·분류·요약 기능을 사용할 수 있습니다.

[Google Drive / OneDrive 연결 안내]
1. '설정·기능'의 클라우드·AI 그룹에서 계정 및 파일 관리를 엽니다.
2. Google Drive 또는 OneDrive를 선택합니다.
3. 앱 Client ID 옆 '?' 버튼에서 공식 등록 절차를 확인합니다.
4. 발급한 Client ID를 입력하고 '공식 로그인으로 연결'을 선택합니다.
클라우드 연결은 선택 사항이며, 계정 비밀번호나 Client Secret을 프로그램에 입력하지 않습니다. 자동 로그인은 사용자가 선택한 경우에만 사용합니다.
