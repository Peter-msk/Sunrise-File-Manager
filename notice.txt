Sunrise File Manager 1.5.5

우클릭 메뉴 정리 · 드라이브 첫 접기 오류 수정 · 휴지통 Delete 지원

[1.5.5 버전 업데이트 내용]

1. 우클릭 메뉴 간소화
- 복사·잘라내기·붙여넣기·삭제 등 기본 작업의 나열을 정리했습니다. 기존 단축키와 상단 메뉴는 그대로 사용할 수 있습니다.
- EIASS 문서명 설정과 AI 정리·요약은 바로 실행하고, 나머지는 열기·보기·파일 정리·압축·목록/경로·공유/클라우드·속성/태그로 묶었습니다.

2. 좌측 탐색기 드라이브 접기 개선
- 열린 드라이브의 화살표를 처음 눌렀을 때 현재 폴더로 스크롤되는 대신 바로 접히도록 수정했습니다.
- 드라이브를 접어도 현재 작업 폴더는 유지하며, 같은 폴더의 새로고침으로 접힌 드라이브가 다시 펼쳐지지 않도록 보완했습니다.

3. 휴지통 Delete 키 지원
- 휴지통에서 항목을 선택하고 Delete 또는 Shift+Delete를 누르면 영구 삭제 확인창을 표시합니다.
- 취소하면 항목을 유지하고, 승인하면 선택한 항목만 삭제합니다.

[Sunrise File Manager 편의 기능]

1. EIASS 제출용 문서명 일괄 변경
선택 PDF에 평가 구분·말머리·4/5자리 번호·제목을 적용합니다. 시작 번호·간격·순서·제목을 조정하고 변경 전 미리보기를 확인할 수 있습니다.
목차 파일(PDF·DOCX·HWPX·HWP·TXT) 또는 직접 입력한 목차로 순서를 맞출 수 있습니다. 번호 없는 목차도 유일하게 일치하는 제목만 연결하며 중복·미일치는 직접 확인합니다.
PDF 내용과 확장자를 유지하고 Ctrl+Z/Ctrl+Y를 지원합니다. EIASS 사이트 업로드와 스캔 목차 OCR은 포함하지 않습니다.

2. 1~4분할과 다중 탭
원본·작업·제출 폴더를 나란히 열어 서로 다른 폴더와 탭을 사용할 수 있습니다.

3. 파일별 메모
검토 의견과 작업 내용을 파일에 연결해 기록하고, 지원하는 이동·이름 변경 작업에서 관련 메모를 함께 처리합니다.

4. 미리보기와 상세정보
파일 목록에서 미리보기·상세정보·메모를 함께 확인하고 미리보기를 독립적으로 열고 닫을 수 있습니다.

5. 문서 본문 검색과 조건 검색
지원 PDF·DOCX·HWPX·일반 HWP 5·XLSX·PPTX 등의 본문을 찾고 이름·확장자·크기·날짜로 목록을 좁힙니다. 보호·암호화 문서와 형식별 읽기 제한이 있는 자료는 검색이 제한될 수 있습니다.

6. 반복 정리와 작업 화면 복원
일괄 이름 변경, 압축 내용 확인·선택 해제, 목록 CSV 내보내기와 함께 탭·폴더·분할·테마·배율·열 너비·보기 설정을 다음 실행에서 이어 사용할 수 있습니다.
