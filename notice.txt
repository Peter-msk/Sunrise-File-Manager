Sunrise File Manager 1.7.0

Sunrise File Manager 1.7.0 버전 안내
1.6.0 대비 변경된 화면 구성과 개선 중인 기능을 안내합니다.

[1.6.0에서 이어지는 기능]
- 1~4분할 탐색과 기존 14개 화면 배치, 다중 탭 및 작업 화면 복원
- 파일 상세정보와 스마트 파일 메모를 각각 독립적으로 열고 닫는 기능
- 미리보기, 폴더 용량 및 SHA-256 확인, 파일별 메모와 기록 복원
- 복사·이동·이름 변경·압축·휴지통·실행 취소·다시 실행
- EIASS 제출용 문서명 정리, AI 기반 파일 관리 및 기존 사용자 설정·메모 데이터 호환

[1.7.0 R09 개발 소스에서 개선된 사항 — 설치본 반영 확인 전]

1. 더 간결한 다중 분할 화면
- 상단의 파일 관리·문서/EIASS·AI 정리·압축/도구 분류 버튼을 화면에서만 제외했습니다. 기능은 삭제하지 않고 '설정·기능 → 작업 명령줄'과 기존 메뉴에서 계속 이용할 수 있도록 했습니다.
- 단일·2분할·3분할·4분할 선택, UI 배율, 테마, 설정을 상단 한 줄에 모으고 업무 명령줄을 별도로 정리했습니다.
- 2~4분할에서 각 탐색창의 반복 메뉴를 줄이고, 필요할 때 고급 명령 메뉴로 열 수 있도록 했습니다.
- 오른쪽 상세정보·미리보기·스마트 메모를 활성 분할창과 연결하고 아이콘 도구로 접근하도록 화면을 정리했습니다.

2. 파일 유형별 스마트 검색
- 검색 대상에서 '전체(파일+폴더)', '파일만', '폴더만'을 선택할 수 있도록 했습니다.
- 한글(HWP/HWPX), PDF, 포토샵(PSD/PSB), 일러스트(AI/EPS/SVG), CAD(DWG/DXF 등), 엑셀(XLS/XLSX/CSV), 이미지, 워드, 프레젠테이션, 압축 파일 등의 유형을 선택해 파일명 검색 결과를 좁힐 수 있습니다.
- 목록에 없는 파일 유형은 .hwp, .pdf, .dwg처럼 확장자를 직접 입력할 수 있습니다.
- 현재 폴더 또는 하위 폴더에서 검색할 수 있으며, '폴더만' 검색 시 파일 내용이나 파일명은 검색 대상으로 검사하지 않습니다.
- 각 탐색창의 검색 유형과 확장자 조건을 별도로 유지해 여러 폴더를 함께 찾는 작업을 돕습니다.

3. Sunrise 전용 파일 속성창
- 파일 또는 폴더의 '속성' 명령에서 Sunrise 전용 창을 기본 화면으로 사용하도록 변경했습니다.
- 이름·형식·위치·크기·날짜·읽기 전용·숨김 속성과 메타데이터를 확인할 수 있습니다.
- 디지털 서명 인증서 정보 및 실행 파일 버전 정보를 볼 수 있고, 특수한 고급 속성이 필요하면 'Windows 원본 속성 열기'를 이용할 수 있습니다.
- 디지털 서명 정보 표시는 서명의 신뢰성 검증과 다르므로 최종 확인은 Windows 원본 기능을 이용해 주세요.

4. 파일 작업 메뉴 사용성 개선
- 파일·폴더 선택과 빈 공간에서 사용하는 우클릭 명령을 구분하고, 복사·붙여넣기·이름 변경·삭제 등의 기본 명령에 접근하기 쉽게 정리했습니다.
- 필요한 경우 Windows 확장 메뉴를 열 수 있으며, 선택 항목이 바뀌었을 때 의도하지 않은 파일 작업이 발생하지 않도록 선택 처리도 보완했습니다.

[적용 및 검증 안내]
- 위 'R09 개발 소스에서 개선된 사항'은 1.7.0 R09 소스 기준의 변경 내용입니다.
- 현재 게시된 1.7.0 설치파일에 R09 기능이 모두 반영됐다는 의미는 아닙니다. Windows 실제 실행 및 설치본 반영 확인 후 최종 적용 여부를 안내하겠습니다.
- 기존 공지·업데이트 방식, 사용자 파일 및 메모 데이터의 호환 정책은 그대로 유지합니다.
