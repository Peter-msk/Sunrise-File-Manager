Sunrise File Manager 1.3.5

Sunrise File Manager 1.3.5에서 파일 탐색과 작업 편의성이 개선되었습니다.

[주요 개선]
- 파일이나 폴더를 이동할 때 목록이 의도치 않게 가로로 움직이는 현상 수정
- 파일 목록 빈 공간을 더블클릭하면 상위 폴더로 이동
- 주소표시줄 클릭 시 현재·상위·최근 방문 위치와 주요 폴더 목록 표시
- 화면 오른쪽 아래 공지사항과 업데이트 버튼을 하나로 통합
- 서로 다른 드라이브 사이의 파일 복사·잘라내기·이동 개선
- 번호가 포함된 폴더·파일명을 숫자 순서에 맞게 정렬
- 라이트 모드 탐색창, 펼침 버튼, 메뉴 구분선 및 종료 설정 저장 안정성 개선
