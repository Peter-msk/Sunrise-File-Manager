Sunrise File Manager 1.5.2

Sunrise File Manager 1.5.2 업데이트 안내

[설치 안정화]
- 설치파일 생성 과정에서 발생하던 오류를 수정했습니다.
- 기본 설치형은 .NET 10 Desktop Runtime x64를 포함합니다.
- 기본 설치형을 사용하는 PC에는 별도 .NET 실행환경 설치가 필요하지 않습니다.

[표시 안정화]
- 3열·4열 및 3행·4행 배치에서 각 탐색창의 최소 표시 공간과 전체 스크롤 범위를 맞췄습니다.
- 단일 화면에서 분할 화면으로 전환한 뒤 파일 목록의 가로 스크롤이 사라지거나 표시 위치가 밀리는 문제를 보완했습니다.

[탐색 편의]
- 좌측 탐색창에서 가로 스크롤과 Shift+마우스 휠로 긴 하위 폴더명을 확인할 수 있습니다.

[기존 기능 유지]
- 파일 탐색·검색·미리보기·메모 및 기존 사용자 설정을 유지합니다.
