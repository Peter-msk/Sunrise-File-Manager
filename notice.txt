Sunrise File Manager 1.6.0

메모 및 파일 상세정보를 독립적인 패널과 기능 시스템으로 분리

[1.6.0 버전 업데이트 내용]

1. 파일 상세정보 독립화
- 상세정보 패널에서 파일명·종류·크기·날짜·위치·읽기전용·숨김 속성을 확인합니다.
- 폴더 용량과 파일 SHA-256 계산을 메모 기능과 독립적으로 실행합니다.

2. 스마트 파일 메모 독립화
- 상세정보 표시 여부와 무관하게 스마트 파일 메모를 독립적으로 열고 닫을 수 있습니다.
- 메모 편집, 작성자, 날짜별 기록, 로컬 암호화 이력 및 AI 요약 기능은 기존 계약을 보존합니다.
- 미저장 메모 확인과 Ctrl+S 저장은 메모 전용으로 유지합니다.

3. 사용자 환경 및 기존 기능 보존
- 각 패널의 열림/닫힘과 너비를 별도 설정으로 저장하며 기존 통합 패널 세션을 읽어옵니다.
- 기존 #memo/*.sunmemo 데이터, 파일 관리, 휴지통 일괄 삭제, Control, 업데이트 호환성을 유지합니다.

[Sunrise File Manager 편의 기능]

1. Windows형 파일 관리, 휴지통, 다중 분할 탐색, 미리보기
2. EIASS 제출용 문서명 정리 및 AI 파일 정리
3. 파일별 메모 작성·기록 복원, 선택 파일의 상세정보 확인
