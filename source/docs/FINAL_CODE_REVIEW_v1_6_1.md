검증 결과: .NET 267개(기존 P16 235 + 이번 32), Python 프록시 25개, PowerShell 증거 8개, 정적 계약 192개. 정적 개수를 실행 시험과 합산하지 않습니다. Linux의 .NET 10.0.13에서 논리 검사, Windows 대상 WPF 교차 게시와 테스트 호스트 경고 0 빌드를 수행했습니다. Windows 네이티브 시험 코드는 컴파일했지만 실행하지 않았습니다.

배포 런타임 기준은 Microsoft 공식 10.0 release metadata입니다: https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json . 2026-10-13 릴리스 10.0.13 및 SDK 10.0.113을 선택했습니다. 런타임 패치는 Core/WPF 각각의 FrameworkReference에 지정하여 WinRT SDK 참조 버전과 혼동하지 않습니다.

미확인과 릴리스 판정: 범용 시방서 34절은 미실행 PASS 추정을 금지하고, 제품 개발계획서 7장은 실제 PC 1대 이상의 파일/UI/권한 시험을 요구합니다. 현재 환경에서 해당 시험이 불가능하므로 코드 인수본은 FINAL, Windows 실기와 정식 배포 승인은 PENDING입니다. 서명/설치 프로그램/자동 업데이트/다중 사용자 Gemini 운영 인증은 추가하지 않았습니다. 런타임을 포함한 포터블 형태이며 무결성 해시는 서명 인증을 대체하지 않습니다.

실기 완료 후 변경 없이 확인된 결과를 별도 Windows 기록으로 추가할 수 있습니다. 확인 중 결함이 발견되면 동일 버전을 덮어 확정하지 말고 수정 버전으로 검증 기록을 갱신합니다.
