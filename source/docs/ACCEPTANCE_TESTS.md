# v1.6.1 Windows 실기 확인표 — 미실행

아래 항목은 자동 로직/교차 빌드 통과와 별도로 Windows PC에서 확인합니다.

1. BUILD_WINDOWS.ps1 실행 후 JSON 단계별 상태, 게시 폴더 전체 실행, 중복 실행 방지 확인.
2. 1개 탐색기 기본, 2·3·4분할, 폴더 트리·탭·검색·정렬·큰 아이콘·우클릭·속성.
3. AI 패널 열기/닫기, 기본 닫힘, 활성 탐색기 선택 유지, 좁은 화면과 100/125/150% DPI.
4. 30개 시험 파일 접두어 변경: 계획 단계 원본 불변, 표의 경로 확인, 최종 승인 후 정확한 결과.
5. 폴더 생성, 일련번호, 복사/이동, 확장자·수정일별 분류 및 기존 대상 폴더 재사용.
6. 충돌 건너뛰기/번호 이름 미리보기, 승인 이후 새 대상 생성 시 재계획 안내, 원본 덮어쓰기 없음.
7. 1,000개 파일 복사·동일 드라이브 이동에서 개수·해시, 전체 진행률·현재 파일·완료/실패/남음 표시.
8. 원본 변조·NTFS 권한 거부·접합점·읽기 전용·장치 이탈·잠긴 파일·중간 취소 후 부분 결과 확인.
9. PDF 표·그림·스캔 페이지, 텍스트 대체모드, DOCX/HWPX 텍스트 미리보기, 썸네일 확인.
10. P11 세션에서 탐색기 경로·분할 복원, 웹 화면으로 복원되지 않음, 기존 Chromium 캐시 삭제 없음.
11. Gemini 미설정·서버 오류·인증 오류 시 일반 탐색기·로컬 명령 계속 사용.
12. Gemini 설정 후 표시된 전송 JSON과 실제 요청을 비교, 파일 내용·실제 경로 자동 전송 없음, 승인 전 파일 변경 없음.

확인되지 않은 항목은 NOT_RUN으로 남깁니다. 실제 문서 대신 일반 시험용 파일만 사용합니다.

## P14 추가 실기 — 미실행

13. Windows 로직 시험의 실제 DPAPI 왕복 성공, 같은 사용자 재시작 후 기록 열기, 다른 사용자/손상 기록에서 복호화 실패 표시.
14. 이름 변경·동일 드라이브 이동 후 재시작 → 기록 조회 → 미리보기 → 승인 → 정확한 경로/내용 복구.
15. 원래 경로에 타 파일 생성, 변경 후 파일 편집, 상위 경로 접합점 치환 시 되돌리기 거부 및 양쪽 파일 보존.
16. 되돌리기 중간 취소 후 완료·미실행 표시, 기록 재조회·새 승인으로 남은 항목만 처리.
17. 시험용 프로세스 강제 종료 시 started / undo_started 기록 검사. 파일을 자동 재실행하지 않고 완료/미실행/확인 필요로 표시.
18. 휴지통 명령의 계획 승인 및 별도 2차 승인. 취소 시 원본 불변. 허용된 소형 파일이 실제 Windows 휴지통에 존재하는지 확인하고 Windows에서 수동 복원.
19. 휴지통 비활성/용량 제한, 네트워크/이동식 드라이브, 권한 거부 조건에서 영구 삭제로 전환되지 않고 실패/확인 필요로 남는지 확인.
20. 기록 쓰기 권한 실패·디스크 공간 부족 시 후속 파일 변경 중단, 기존 기록 손상 시 자동 덮어쓰기/삭제 없음.

휴지통 API와 DPAPI는 교차 컴파일만으로 실제 성공 판정을 내리지 않습니다.

## P15 추가 실기 — 미실행

21. 동일 내용/다른 이름, 동일 크기/다른 내용, 빈 파일, 하드 링크를 섞어 중복 그룹과 검사 개수를 확인합니다. 원본 개수·해시가 변하지 않아야 합니다.
22. 대형 폴더에서 파일 수·전체 탐색 수·바이트 상한 도달, 중간 취소, 접근 거부·접합점 제외를 확인합니다. 부분 결과 표기가 명확해야 합니다.
23. 유형별·크기별·연도별 복사/이동의 계획과 실제 결과를 확인하고 기존 충돌·기록·되돌리기 회귀를 확인합니다.
24. 내용 읽기 동의 전 차단, 다중 규칙 일치/미분류 제외, 16,000자 접두부 제한·지원 형식 제한을 확인합니다. 분류 계획을 가져오기만 해서는 파일이 변경되지 않아야 합니다.
25. 외부 등급 기본 내부자료, 내부/보호 전송 차단, 일반자료도 전송 내용 확인 필요, 요청문·파일명·임시 ID 외 문서 내용 자동 전송 없음.
26. 일일 시도 상한·UTC 날짜 전환·네트워크 실패 계수, 모델·토큰 미제공 응답 표시, 마지막 사용량 기록에 파일명·본문·키가 없는지 확인합니다.
27. 실제 운영 계정/모델이 정해지면 사용량과 예상 금액 안내를 검증합니다. 미산정을 무료로 해석하지 않습니다.


## P16 / 최종 코드본 추가 확인 — 미실행

28. 760px 폭부터 넓은 창, 1·2·3·4분할, F8, 오른쪽/아래 AI 배치, 검색 줄바꿈과 보조 패널, 100/125/150/200% DPI를 확인합니다.
29. 완료 직전/오류 팝업 동안 진행률이 완료·실패 요약을 덮지 않는지 확인합니다. 큰 이미지 폴더 전환에서 취소된 썸네일이 나타나지 않아야 합니다.
30. 손상·잘못된 구조·과도한 크기의 session.json에서 경고와 기본 배치로 시작하는지 확인합니다. 정상 이전 세션은 호환되어야 합니다.
31. 결과 불확실 기록을 검사한 뒤에도 확인 필요 상태가 남고 자동 되돌리기가 차단되는지 확인합니다.
32. BUILD_WINDOWS.ps1의 네이티브 소규모 검사(DPAPI·승인된 이름 변경·기록 재열기·되돌리기·복사)와 게시 결과를 보존합니다. 이 검사는 임시 시험 파일만 사용하며 휴지통은 실행하지 않습니다.

배포 승인 기록에는 Windows 버전, DPI, 시험 일시, 통과/실패, 오류 로그를 함께 남깁니다. 미실행을 PASS로 바꾸지 않습니다.


## v1.7.0 전면 수정 확인 — 현재 미실행

33. 기존 앱 종료 후 새 폴더에서 실행하고 창 제목 v1.7.0을 확인합니다. 모든 메인/이름 입력/기록/검사/미리보기 창이 밝은 테마와 읽을 수 있는 글자로 나오는지 확인합니다.
34. 바로 가기, 드라이브 트리, 탭/새 탭/탭 닫기/탭 휠 이동, 주소 입력·검색·정렬, 단일/2/3/4분할, 도구 오버플로, F8을 확인합니다.
35. 일반 시험 파일을 Ctrl+C 또는 Ctrl+X로 준비하고 다른 폴더로 이동해 Ctrl+V, 확인 취소/승인, 충돌 정책, 다른 드라이브 이동 제한을 확인합니다. 실제 업무 파일로 첫 시험을 하지 않습니다.
36. HWPX 저장된 첫 쪽 이미지/저장된 텍스트/미리보기 없음, 85MB급 파일, HWP 안내, 확대·이전/다음, 연결 앱 열기를 구분해 확인합니다. 저장된 첫 쪽을 전체 문서 렌더링으로 해석하지 않습니다.
37. 첨부에서 보인 한글의 검은 본문은 Windows 탐색기에서 같은 원본을 열었을 때의 결과와 비교해 원인을 좁힙니다. 원인 확인 없이 자동 변환·원본 수정·보안 설정 변경으로 처리하지 않습니다.
38. VERIFY_UI_WINDOWS.ps1의 시험용 화면 결과를 확인합니다. 현재 DPI 이외의 배율과 외부 한글 편집기 렌더링은 별도 확인합니다.
