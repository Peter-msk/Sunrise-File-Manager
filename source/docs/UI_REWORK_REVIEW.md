# v1.7.0 UI 전면 수정 검토

## 관찰과 범위

사용자 화면에서 흰 메인 창/짙은 탐색기 패널/검은 글자/흰 기본 ComboBox가 혼재하고, 큰 제목·반복 헤더·미리보기/정보/정리 영역이 파일 목록 공간을 줄이는 문제가 확인되었습니다. 새 코드는 밝은 공통 팔레트와 명시적인 AppWindow 스타일을 모든 파생 Window에 적용합니다. UserControl과 동적으로 생성하는 트리 항목의 고정 흰 글자도 제거했습니다. 화면을 보지 않고 이전 버전을 최종 UI로 평가한 판단은 철회합니다.

## 구현

- 메인: 48px 헤더, 단일/분할 선택과 선택형 파일 정리. 작업 중에만 진행/취소 표시.
- 탐색기: 36px 탭, 44px 주소/검색(좁으면 84px), 42px 명령 도구, 남은 영역은 파일 목록. 880px 고정 도구 행 대신 WPF 도구 오버플로 사용.
- 탐색 영역: 홈/바탕화면/문서/다운로드, 드라이브와 폴더 아이콘. 기본 정보 패널 닫힘. 정상 기존 탭/폴더/분할 설정은 유지.
- 목록: 13px 본문과 36px 행, 폴더/문서 유형 아이콘, 명확한 선택 행. 가상화와 유한 작업 영역 유지.
- 조작: 복사/잘라내기/붙여넣기와 Ctrl+C/X/V를 기존 TransferService 및 승인 UI로 연결. 단일 패널에서도 대상 폴더 이동 후 붙여넣기 가능. 패널 간 전송도 기존 공통 경로 사용.
- 미리보기: 원본 연결 앱과 내부 미리보기를 구분. HWPX의 저장된 PNG/텍스트를 우선 조회하여 이미지가 많은 85MB 문서도 전체 본문 추출 없이 미리보기 접근. PNG 크기/차원, 텍스트 접두부, 아카이브 크기 상한. 원본 변환/수정/디스크 추출 없음.
- 이미지 디코딩: 미리보기/썸네일이 공통 2차원 픽셀 예산을 사용. 미리보기 확대 시 페이지 표면과 스크롤 범위를 함께 확대.
- 한글 원본: 더블클릭은 기존과 같이 Windows 연결 앱으로 열기. 첨부된 외부 한글 편집기의 검은 본문은 원인 미확정이며 해결 PASS로 표시하지 않습니다. HWP의 내부 페이지 렌더링도 지원한다고 표시하지 않습니다.

## 검증

Linux 실행 논리 282개 PASS: 저장 미리보기 우선순위, 85MB ZIP, UTF-8 한글, 텍스트 제한, 잘못된 PNG/차원, 원본 해시 보존, 취소, HWP 제한 안내 및 기존 파일/기록/분류 회귀. UI/테마 소스 계약 12개, 빌드 증거 8개, 정적 계약은 각 로그에 구분합니다. 글자 대비는 공통 글자·보조 글자와 목록/창/선택 배경의 수치 기준을 검사했으며 모든 네이티브 컨트롤의 실제 픽셀 측정을 뜻하지 않습니다.

WPF 게시 및 네이티브 UI 호스트 컴파일은 경고를 오류로 처리해 통과했습니다. VERIFY_UI_WINDOWS.ps1의 실제 실행은 NOT_RUN입니다. 이 검사는 시험용 폴더만 사용하고 세션 저장/기존 이력 조회를 생략합니다. 6개 배치(1440×900, 1024×768, 900×650, 2/4분할, 정리 열림/닫힘)를 렌더링하여 JSON/PNG를 PC에 기록합니다. 이 화면을 여기서 본 것으로 보고하지 않습니다.

시방서 v1.3 FINAL의 입력/부작용 경계, 자원 수명, 공통 원인 수정, 변경영향과 미실행 구분을 적용했습니다. 저수준 파일 전송·승인·암호화 기록 schema·프록시 계약은 유지합니다. 새로운 외부 dependency는 없습니다. 실제 Windows UI/고DPI/클립보드/한글 원본 검증 후 사용자 확인이 필요합니다.
