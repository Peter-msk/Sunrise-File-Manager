# P15 로컬 검사·분류 작업 인수인계

- 버전: v1.5.0 / P15
- 기준: v1.4.0 / P14 (기준본 보존)
- 적용: 범용 코드작성 시방서 v1.3 FINAL
- 상태: 구현·로컬 검증 완료, Windows 실기·Gemini 운영 검증 대기

## 변경 소유권

| 영역 | 구현 |
|---|---|
| AiInspectionService | 명시적 파일/폴더 범위, 상한·접근 실패·링크 제외·취소, 크기 사전 그룹화, 스트리밍 SHA-256, 검사 전후 변경 검사 |

| AiContentClassifier | 로컬 텍스트 접두부 키워드 분류, 동의 검사, 모호·미분류 표시, 외부 등급/승인 경계 |

| AiCommandPanel | 검사 창 연결, 일반/내부/보호 등급, 외부 전송 미리보기·사용량 표시 |

검사는 읽기 전용입니다. 분류 실행은 기존 계획 검증 → 미리보기 → 명시적 승인 → 기존 파일 서비스 → P14 암호화 기록 경로를 따릅니다. 중복 검사에서 자동 정리·삭제를 연결하지 않았습니다.

## 범위의 정확한 의미

P15의 내용 분류는 **로컬 텍스트 키워드 분류**로 구현했습니다. 문서 본문을 Gemini로 전송하는 경로는 추가하지 않았습니다. PDF·DOCX·HWPX의 의미 분석·OCR은 포함하지 않습니다. 텍스트 앞부분 최대 16,000자의 결과이므로 전체 문서 분석이나 확정된 업무 분류로 과장하지 않습니다.

확인 필요/미분류/지원하지 않는 형식은 보고서에 표시하고 파일 작업에서 제외합니다. 분류 계획을 메인 패널에 가져온 뒤 별도로 승인해야 합니다. 사용자 지정 보안 등급은 외부 전송을 제어하지만 OS/보안 프로그램의 정책 판정 자체를 대체하지 않습니다.

사용량의 가격은 계정·모델·운영 과금 조건이 없으므로 숫자를 만들지 않고 **미산정**으로 표시합니다. 실제 계정으로 예상 금액을 검증한 결과가 아닙니다. 토큰 정보가 없는 서버는 미제공으로 표시합니다. API 실연결은 수행하지 않았고 비승인 등급/동의 누락이 네트워크 경계 전에 차단되는 자동시험을 수행했습니다.

## 제한 및 후속 게이트

- Windows GUI·대량 파일 실기·NTFS 권한·DPAPI·Shell 휴지통·Gemini 실제 호출은 NOT_RUN.
- 동일 내용의 하드 링크도 복수 경로로 보일 수 있어 실제 확보 가능 용량을 표시하지 않습니다.
- 해시 결과는 검사 시점 관찰값입니다. 실행할 파일 정리는 별도 재검증이 필요합니다. 의도적인 동시 경로 치환을 모두 봉쇄한 핸들 잠금 구현은 아닙니다.
- 동시성은 단일 검사 작업이며 전체 트리 탐색 50,000개, 오류 상세 최대 200건, 발견 파일 최대 50,000개로 제한합니다.
- 읽기 상한은 중복 해시 읽기에 적용합니다. 내용 분류 상한은 선택 파일 크기 합계이며 기존 실행 검증의 해시 I/O와 합쳐진 물리 디스크 총량 한도는 아닙니다.
- 일일 시도 한도는 UTC 기준 로컬 편의 제어입니다. 운영 제공자의 과금 한도와 서버 권한 정책은 별도 설정해야 합니다.

다음 단계는 P16 UI·성능·배포 안정화입니다. Windows 실제 자료로 UI 가독성·진행률·고DPI·큰 폴더·취소 응답성을 먼저 확인하고, 운영 모델이 정해진 뒤 비용 안내를 검증합니다. 이미 통과한 Python 검사를 Windows 빌드마다 반복하지 않습니다.
