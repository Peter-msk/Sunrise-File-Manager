# Sunrise File Manager 1.0.0

Sunrise Group의 Windows 10/11 x64용 .NET 10 WPF 파일 관리자입니다. 여러 폴더를 한 화면에서 관리하고, 문서와 이미지를 미리 보며, 파일별 메모와 선택형 AI 정리 기능을 사용할 수 있습니다.

## 주요 기능

- 1~4분할 탐색기와 탭, 폴더 검색 및 파일 분류
- 파일 복사·이동·이름 변경·삭제·압축
- PDF, HWPX, DOCX 및 이미지 미리보기
- 문서 확대·축소, 너비 맞춤 및 별도 미리보기 창
- 파일별 공유 메모 `#memo`
- 별도 창에서 실행하는 AI 파일 정리 기능
- 선택형 로컬 Ollama 연동
- 창과 작업 상태 복원, 라이트·다크 테마

## 최신 업데이트

- `설정 · 기능 > 공지사항 · 버전 정보`에서 제품 공지와 버전을 확인할 수 있습니다.
- `업데이트 확인`에서 새 버전 제공 여부를 확인할 수 있습니다. 새 설치 파일이 배포되면 안내에 따라 업데이트를 진행할 수 있습니다.
- AI 파일 정리 창과 문서 미리보기 조작을 개선했습니다.

## 실행 및 빌드

- Windows 10/11 x64 환경이 필요합니다.
- 소스 빌드에는 .NET 10 SDK가 필요합니다.
- 개발 확인용 빌드는 `BUILD_DEV_EXE.cmd`를 실행합니다.
- 설치 파일 빌드는 `BUILD_ON_WINDOWS_COMPANY.cmd`를 실행합니다.
- Ollama 연동은 선택 사항이며, 사용하려면 로컬 Ollama 환경을 별도로 준비해야 합니다.
