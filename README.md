# Sunrise File Manager

**최신 정식 버전: v1.7.5** · **배포일: 2026-10-28** · **Windows 10/11 x64** · 설치형 데스크톱 파일 관리자

Sunrise File Manager는 여러 작업 폴더를 한 화면에서 비교·정리하고, 로컬 PC·네트워크·클라우드 저장소의 파일을 효율적으로 관리하도록 만든 Sunrise Group의 파일 관리 프로그램입니다. 클라우드 계정이나 AI 연결 없이도 일반 파일 관리 기능을 사용할 수 있습니다.

**[v1.7.5 정식 설치파일 내려받기](https://github.com/Peter-msk/Sunrise-File-Manager/releases/tag/v1.7.5)**  
설치파일 이름: `Sunrise_File_Manager_1.7.5_Setup.exe`

## 1. 주요 기능

| 기능 그룹 | 제공 기능 |
| --- | --- |
| 파일 탐색·관리 | 다중 탭, 1~4분할 작업 창, 복사·이동·이름 변경·삭제, 압축·압축 해제, Windows 휴지통 탐색·복원 |
| 검색·문서 | 파일명·확장자·크기·날짜 등 조건 검색, 지원 문서 본문 검색, 파일 미리보기·상세정보·메모 |
| 업무 편의 | 폴더 비교, 단방향 동기화, 목록 내보내기, EIASS 제출용 PDF 파일명 일괄 변경·적용 전 미리보기 |
| 클라우드 | Google Drive·OneDrive 선택적 계정 연결, 원격 폴더 탐색, 업로드·다운로드 및 지원되는 파일 작업 |
| 안전 전송 | 분할창 간 복사, 드래그 앤 드롭, 확인 후 안전 이동, 충돌·취소·일부 성공·오류 안내 및 조건부 전송 재개 |
| 화면·접근성 | 라이트·다크 테마, 라이트 모드 맞춤 색상, 화면 배율, 보조 패널 표시, 키보드 포커스 이동 |
| AI(선택) | 별도로 설치한 로컬 Ollama를 통한 지원되는 파일 검색·분류·요약 보조 기능 |

> **파일 안전:** 복사·이동·동기화는 대상과 결과를 확인한 후 진행하세요. 지원되는 경로에서 내용 확인 및 충돌 보호를 적용하지만, 모든 외부 저장소에서 모든 작업이 동일하게 지원되는 것은 아닙니다.

## 2. v1.7.5 업데이트 내용

- **기능별 메뉴 정리:** 상단 **설정·기능** 메뉴를 파일 관리, 검색·문서, 분할·작업 공간, 전송·복구, 클라우드·AI, 패널·화면, 프로그램 정보의 **7개 그룹**으로 구성했습니다.
- **클라우드 관리창 개선:** **연결 설정 / 원격 탐색 / 파일 작업**을 구분하고, **앱 Client ID 입력칸의 `?` 도움말**에서 Google Drive·OneDrive 발급 절차를 확인할 수 있습니다.
- **1~4분할과 목록 작업 개선:** 여러 저장소를 나란히 탐색하고 검색·정렬·페이지 처리, 보조 패널 공간 배분 및 스크롤 안내를 개선했습니다.
- **안전한 전송과 결과 표시:** 분할창 복사·검증 후 이동·폴더 비교·단방향 동기화, 오류·중단·재개 조건, 성공·실패·건너뜀·취소 상태 표시를 보완했습니다.
- **화면 및 접근성 개선:** 라이트 테마 맞춤 색상, DPI 대응, 단축키 및 포커스 이동, 미저장 메모 보호를 개선했습니다.

자세한 내용은 **[공식 업데이트 공지](https://github.com/Peter-msk/Sunrise-File-Manager/blob/main/notice.txt)**에서 확인할 수 있습니다.

## 3. 빠른 시작

1. [v1.7.5 릴리스 페이지](https://github.com/Peter-msk/Sunrise-File-Manager/releases/tag/v1.7.5)에서 설치파일을 받습니다.
2. Setup을 설치하고 Sunrise File Manager를 실행합니다.
3. 탐색 창에서 로컬 드라이브나 네트워크 폴더를 열고, **탭·1~4분할**로 작업 폴더를 배치합니다.
4. 상단 **설정·기능** 메뉴에서 목적에 맞는 그룹을 선택합니다.
5. 파일을 선택하여 복사·이동·검색·미리보기·메모 등의 기능을 사용합니다.
6. 대량 이름 변경·폴더 동기화·안전 이동은 **미리보기 및 대상 확인 후** 진행합니다.

### 유용한 키보드 조작

| 키 | 기능 |
| --- | --- |
| `F6` | 다음 작업 영역으로 포커스 이동 |
| `Shift+F6` | 이전 작업 영역으로 포커스 이동 |
| `Alt+Shift+F` | 파일 작업 공간 집중 모드 |

닫혀 있는 패널을 강제로 열지 않으며, 작업 영역 이동만으로 파일을 수정하지 않습니다.

## 4. Google Drive·OneDrive 연결 및 Client ID 발급

클라우드 기능은 **선택 사항**입니다. 연결하지 않아도 PC와 네트워크 파일을 관리할 수 있습니다.

1. **설정·기능 → 클라우드·AI → Google Drive·OneDrive 계정 및 파일 관리**를 엽니다.
2. **Google Drive** 또는 **OneDrive**를 선택합니다.
3. **앱 Client ID** 옆의 **`?`**를 눌러 해당 서비스의 공식 발급 안내를 읽습니다.
4. 발급한 **Application / OAuth Client ID**를 입력합니다. OneDrive 조직 계정에서 필요한 경우에만 테넌트 값을 설정합니다.
5. **공식 로그인으로 연결**을 누르고 시스템 브라우저에서 로그인·권한 동의를 완료합니다.
6. 연결 후 **원격 탐색**과 **파일 작업** 영역에서 폴더 및 파일을 관리합니다.

**Google Drive:** [Google Cloud OAuth 클라이언트 ID 생성 안내](https://developers.google.com/workspace/guides/create-credentials) — 프로젝트 선택, Google Drive API 활성화, OAuth 동의 화면 구성, **데스크톱 앱** 유형으로 클라이언트 생성.

**OneDrive:** [Microsoft Graph 앱 등록 안내](https://learn.microsoft.com/en-us/graph/auth-register-app-v2) — Microsoft Entra 앱 등록, 지원할 계정 유형 선택, **모바일 및 데스크톱** 플랫폼과 `http://localhost` 리디렉션 설정, 필요한 Microsoft Graph 위임 권한 확인.

**보안 안내:** 계정 비밀번호·Client Secret·자격증명 JSON 전체를 앱 Client ID 입력칸에 넣지 마세요. 자동 로그인은 사용자가 선택한 경우에만 이용하며, 저장 대상 갱신 토큰은 사용자 환경에 암호화하여 보관하도록 설계되어 있습니다. 조직 계정은 관리자의 앱 사용 승인이나 권한 동의가 필요할 수 있습니다.

## 5. 사용자 편의기능 활용

- **폴더 정리:** 두 분할창에 원본과 대상을 열면 반복적인 복사·이동과 비교가 편리합니다.
- **문서 검토:** 파일 목록 옆에서 미리보기·상세정보·메모를 확인해 창 전환을 줄일 수 있습니다.
- **대량 문서 관리:** 검색 조건과 파일명 일괄 변경의 적용 전 미리보기로 실수를 줄일 수 있습니다.
- **전송 결과 확인:** 성공·실패·건너뜀·취소·미시작 수를 확인하고 미확정 작업은 대상 파일을 직접 점검하세요.
- **화면 맞춤:** 분할 작업 공간, 보조 패널 및 라이트 테마 색상을 업무 환경에 맞춰 설정할 수 있습니다.
